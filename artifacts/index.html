Architectural Artifacts

Product requirements, C4 diagrams, data model, and API reference for Cartculate — describing the system as actually implemented.

A note on accuracy

These documents describe Cartculate as actually built — in cartculate-app (React Native + TypeScript) and cartculate-server (Spring Boot 4.1 / Java 25) — not an aspirational or original-spec state. Wherever the original product spec described something not yet built, it's marked ○ Planned rather than documented as if it exists.

Where this folder lives

Place this whole artifacts/ folder at your project root, as a sibling to your frontend and backend folders:

your-project-root/ ├── cartculate-app/ (React Native frontend) ├── cartculate-server/ (Spring Boot backend) └── artifacts/ (this folder) ├── index.html ├── styles.css ├── prd.html ├── c4-diagrams.html ├── data-model.html ├── architecture-decisions.html └── api-reference.html

Open index.html directly in a browser — everything (Mermaid diagrams included) renders client-side via CDN, no build step or local server required.
